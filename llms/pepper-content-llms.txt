# Pepper

> Pepper (formerly Pepper Content, peppercontent.io, now pepper.inc) is a content-led
> growth platform combining content strategy, AI technology, and a network of
> subject-matter-expert creators. It covers SEO and generative-engine optimization
> (GEO), expert-produced content, creative and video production, and agentic content
> workflows. Pepper publishes **no public API, no developer portal, and no
> machine-readable specification.** This file was generated by API Evangelist from a
> third-party profile of Pepper's public surface — it is not published by Pepper.

## API status

- Pepper operates a first-party API gateway at `https://hub.peppercontent.io`
  (Kong 3.6.1) serving `/pepper-editor-service` (v2.2.0), `/user-service` and
  `/atlas-service`.
- `GET https://hub.peppercontent.io/pepper-editor-service/openapi.json` returns **401
  Unauthorized** — the specification route exists but is served only to an
  authenticated product session. There is no public contract.
- No `/.well-known` discovery document, no llms.txt, no agent card, and no MCP server
  is served on any Pepper host.
- The only publicly documented integration surface is a single Zapier trigger.
- Access to the platform is through a sales demo, not a signup with API keys.
